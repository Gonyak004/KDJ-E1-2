완료
- Python 3.15.2 / 표준 라이브러리만 사용
- Python 기초 퀴즈 7개 / Quiz, QuizGame, StateStore 클래스
- 메뉴 / 퀴즈 풀이 / 등록 / 목록 / 최고 정답 수 확인
- 공백, 빈 입력, 숫자 변환 실패, 범위 오류 검증
- Ctrl+C, EOF 안전 종료 및 저장
- 프로젝트 루트 state.json에 UTF-8 저장 / 재실행 후 유지
- 파일 없음, JSON 손상, 잘못된 스키마, 읽기·쓰기 오류 처리
- 손상 원본 별도 보관 / 임시 파일을 통한 저장
- 자동 테스트 14개 통과
- 기능별 커밋 10개 이상 / 별도 브랜치 checkout 및 merge
- Gonyak004 저장소 clone / 복제본 수정·commit·push / 원본 pull 및 HEAD 일치 확인
- 커밋 작성자 Gonyak004 통일 / 이전 GitHub 인증 제거

증빙
- screenshots/: 실행 원문을 표시한 Windows 실행 기록 뷰어의 PNG 캡처 13개
- logs/: 캡처에 사용한 수정하지 않은 실행 출력 및 입력 재현 로그
- logs/01: 메뉴 검증 및 미플레이 점수
- logs/02: 퀴즈 추가 및 정답 범위 검증
- logs/03: 재실행 후 추가 퀴즈가 포함된 목록
- logs/04: 정답·오답 및 최종 결과
- logs/05: 재실행 후 최고 점수 유지
- logs/06: Python·Git 버전, 작성자, 본인 원격 주소
- logs/07: 테스트 결과
- logs/08: Git 커밋 그래프와 브랜치 병합
- logs/09: 실제 clone/push/pull 명령 실행 기록
- logs/sample-state.json: 격리된 증빙 실행에서 저장된 예시 데이터

참고
- 캡처 시나리오는 임시 폴더에서 실행하므로 실제 state.json을 오염시키지 않는다.
- 루트 state.json은 첫 실행 시 자동 생성하며 개인 진행 데이터라 Git에서 제외했다.
- practice-clone/은 clone 실습용 로컬 복제본이며 Git에서 제외했다.
- 최고 점수는 전체 풀이에서 맞힌 문제 수의 최댓값이다.
