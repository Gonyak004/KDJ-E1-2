Git 저장소 복제 및 동기화 실습

원격 저장소: https://github.com/Gonyak004/KDJ-E1-2

1. 기존 작업 폴더에서 git clone으로 practice-clone 폴더를 생성했다.
2. 복제한 저장소에서 이 실습 기록 파일을 새로 추가했다.
3. 복제한 저장소에서 변경을 commit하고 origin/main에 push했다.
4. 기존 작업 폴더에서 git pull --ff-only로 이 기록을 가져온다.
5. 두 저장소의 HEAD가 같은지 비교하여 동기화를 확인한다.

이 파일은 README 작성 전에 수행한 clone/push/pull 실습의 변경 대상이다.
